## Meeting Purpose

The purpose of this meeting was to continue visual and design planning for the cybersecurity game prototype. The team focused on the game background, room layout, objects, badges, main character, enemy character, and user interface design.

## Agenda Items

5. Discussion of UI design for game interfaces.
6. Review of responsibilities for the next development stage.

## Discussion Summary

The team discussed how the game should look and feel visually. A **dark theme** was selected because it fits the escape-room and cyber-horror style of the game. The theme was considered suitable because it creates tension and makes the game environment more engaging for the target audience.

The team also discussed the contents inside the game room. Objects such as doors, computer screens, warning signs, cybersecurity items, obstacles, and interactive objects were considered important for making the room meaningful and connected to the cybersecurity learning theme.

Game badges were discussed as a reward system. The team agreed that badges can motivate players and show progress after completing cybersecurity challenges. This supports replayability and makes the learning experience more engaging.

The main character and enemy character ideas were also discussed. The main character will represent the player, while the enemy will create pressure and make the game more challenging.
