How to Play

  • Move using WASD or Arrow Keys.
  • Pause using ESC.
  • Only the next door is shown, so the maze stays clean.
  • Correct answers unlock doors and give Cyber Coins.
  • Hints cost 1 Cyber Coin.
  • Wrong answers buff the fish and return you to the game.
  • 3 Cyber Coins can revive you with full health.
  • The final door needs a strong password. Once locked, the fish cannot follow.

Parental Controls

  • The game supports safe gameplay for younger users.
  • Scores and progress are stored locally in the browser.
  • No public chat, voice chat, friend requests, or direct messaging.
  • No microtransactions, loot boxes, or real-money purchases.
  • Players are encouraged not to use real names or personal information.
  • Gameplay can be paused with ESC for supervision or breaks.

Terms and Conditions

  • This game is for educational cybersecurity awareness.
  • Accounts, scores, and best times are stored locally in the browser cache/localStorage.
  • Do not enter real personal data, addresses, or financial details.
  • Players must not exploit bugs or modify game files unfairly.
  • This game is designed mainly for users aged 11–16.
  • Game features may be improved in future versions.
