# Parental Controls

The game includes parental control features to support safe and appropriate gameplay for younger audiences.

1. Players may receive optional reminders after extended gameplay sessions to encourage healthy screen time habits.

2. Parents or guardians can view player progress, completed levels, scores, and learning statistics.

3. User accounts, progress, and game data are stored locally on the device and are not shared externally.

4. The game does not include public chat systems, voice chat, friend requests, or direct messaging features.

5. The game does not contain microtransactions, premium currency, loot boxes, or real-money purchases.

6. Parents may adjust or disable music and sound effects to create a suitable gameplay environment.

7. Players are encouraged not to use real names or personal information when creating usernames.

8. Players can pause gameplay when required to support supervised play or interruptions.

9. The game does not require players to provide personal information beyond basic login credentials required for local account creation.
