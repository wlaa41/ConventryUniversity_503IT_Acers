## Accessibility Features

The game incorporates accessibility considerations to improve usability and inclusivity:

• High contrast user interface elements to improve visibility

• Colour-blind friendly visual indicators that do not rely solely on colour-based communication

• Subtitles and text descriptions for educational feedback popups

• Adjustable game audio controls

• Difficulty progression system allowing players to learn gradually

• Simple keyboard controls requiring minimal inputs

• Pause functionality during menu navigation

• Clear visual feedback when selecting answers

• Timer indicators displayed visually rather than audio-only notifications

These accessibility considerations attempt to reduce barriers and create a more inclusive learning environment for different player needs.
